# Orca Notch

A Mac-only notch app for people who run AI coding agents. A small mascot lives in the notch (or in a bar at the top of a screen without one), shows your agent sessions as they work, and lets you approve, answer and jump to the right terminal without leaving what you're doing.

Orca Notch is a fork of [Louis-CFM/coucou](https://github.com/Louis-CFM/coucou) (MIT), stripped down to the notch island and rebranded. It is being turned into the notch companion of Orca, the agent workspace manager. The Orca data sources (`NotchBuddy/Sources/OrcaKit`) land separately.

> The upstream project's name, character, icon and sounds are not free to reuse (see [`LICENSE-ASSETS.md`](LICENSE-ASSETS.md)). This fork ships none of them: the mascot is a placeholder whale drawn in code, the icons are generated by `scripts/make-icons.swift`, and the only sounds are macOS system sounds.

## What it does

- **Agent sessions in the notch** — Claude Code, Cursor, Codex, Gemini CLI, Antigravity, Copilot CLI, Muse Code, OpenCode, Amp, Hermes and Claude Desktop, live, step by step. Tag a hook payload with `orca_notch_agent` to give any other agent its own pill.
- **Approve and answer from the notch** — Claude Code permission requests with Allow / Deny / Always, `AskUserQuestion` prompts (single or multi-select), plan approval, and Allow / Deny for Codex. Nothing is approved without an explicit click.
- **Jump to the right terminal** — open the exact terminal window of a session.
- **Diffs** — see what an agent is editing (file name, +N −M), tap for the full diff.
- **Chat with Claude** — with your own Anthropic API key, with web search; drop a file on the notch or drag the mascot onto a window to attach it as context.
- **Plan usage** — Claude and Codex limits in the notch header, if you turn them on.
- **GitHub pulse** — open PRs, review requests and CI status, with a personal access token.
- **Shortcuts** — configurable global hotkeys for the island, the chat, the next alert, the terminal and more.

## Build

```bash
brew install xcodegen
cd NotchBuddy && xcodegen && xcodebuild -scheme NotchBuddy -configuration Debug build
```

To run it day to day: `./scripts/dev-install.sh` builds it and installs it in `~/Applications`.

Unit tests are plain Swift scripts: `for t in scripts/test-*.sh; do bash "$t"; done`.

Requirements: macOS 15+, the Xcode version set in `project.yml`, [XcodeGen](https://github.com/yonaskolb/XcodeGen).

## Hooks

Orca Notch installs a small relay at `~/Library/Application Support/OrcaNotch/nb-hook` and wires it into the agents you choose in Settings → Agents. It never overwrites `~/.claude/settings.json`: it makes a dated backup, merges, shows the diff and writes only after you confirm. If the app does not answer, the hook exits immediately and never blocks the agent.

## Privacy

No telemetry. Network calls go only to services you configured (Anthropic for the chat, GitHub for the pulse). Secrets live in the Keychain.
