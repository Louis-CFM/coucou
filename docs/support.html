FAQ

macOS says it can’t verify the app

The current Mac build isn’t notarized by Apple yet. The first time, open System Settings → Privacy & Security, scroll down and click Open Anyway. You only need to do it once.

Where is the Windows download?

It is paused for now. Microsoft Defender wrongly flags the unsigned Windows installer as malware; a false-positive report is under review at Microsoft, and the installer will come back once it’s cleared and signed. Until then you can build it from source.

Mochi doesn’t show my Claude Code sessions

Open Settings → Claude Code → Install hooks, review the changes, confirm, then start a new Claude Code session.

The chat doesn’t answer

Add your Anthropic API key in Settings. API usage is billed by Anthropic, separately from a Claude subscription.

An integration pill stays grey

Check its key in Settings → Integrations. Up to 4 integrations can be shown at once.

No sound

Check the speaker icon in the notch header and the volume in Settings.

Does it work without a notch?

Yes. On an iMac, a Mac mini, or any Mac connected to an external display, Mochi sits in a small bar at the top of the screen instead of inside a notch.

How do I uninstall?

Settings → Claude Code → Uninstall (removes only Coucou’s hooks), then quit the app and move it to the Trash. Optionally delete ~/Library/Application Support/NotchBuddy.

On Windows: same Uninstall button for the hooks, then Windows Settings → Apps → Coucou → Uninstall. Optionally delete %LOCALAPPDATA%\Coucou.

Questions fréquentes

macOS dit qu’il ne peut pas vérifier l’app

La version Mac actuelle n’est pas encore notarisée par Apple. La première fois, ouvre Réglages Système → Confidentialité et sécurité, descends et clique sur Ouvrir quand même. Une seule fois suffit.

Où est le téléchargement Windows ?

Il est en pause pour le moment. Microsoft Defender détecte à tort l’installeur Windows (non signé) comme un malware ; un signalement de faux positif est en cours d’analyse chez Microsoft, et l’installeur reviendra dès que ce sera réglé et signé. En attendant, tu peux le compiler depuis le code source.

Mochi n’affiche pas mes sessions Claude Code

Réglages → Claude Code → Install hooks, vérifie les changements, confirme, puis lance une nouvelle session Claude Code.

Le chat ne répond pas

Ajoute ta clé d’API Anthropic dans les Réglages. L’API est facturée par Anthropic, à part d’un abonnement Claude.

Une pastille d’intégration reste grise

Vérifie sa clé dans Réglages → Intégrations. Jusqu’à 4 intégrations s’affichent en même temps.

Pas de son

Vérifie l’icône haut-parleur dans l’en-tête du notch et le volume dans les Réglages.

Ça marche sans notch ?

Oui. Sur un iMac, un Mac mini ou un Mac branché à un écran externe, Mochi s'affiche dans une petite barre en haut de l'écran plutôt qu'à l'intérieur du notch.

Comment désinstaller ?

Réglages → Claude Code → Uninstall (retire seulement les hooks de Coucou), puis quitte l’app et mets-la à la corbeille. Tu peux aussi supprimer ~/Library/Application Support/NotchBuddy.

Sous Windows : le même bouton Uninstall pour les hooks, puis Paramètres Windows → Applications → Coucou → Désinstaller. Tu peux aussi supprimer %LOCALAPPDATA%\Coucou.
