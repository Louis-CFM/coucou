Support

Something wrong, or an idea for Mochi? Here’s how to get help.
Report a bug or request a feature: open an issue on GitHub (fastest).
Email: raillelouis@gmail.com

FAQ

How do I get Coucou on my iPhone?

Install TestFlight from the App Store, then join the TestFlight beta. The beta is free; Apple limits it to 10,000 testers. Then turn on Settings → General → iPhone in the Mac app (0.1.9 or later) and use the same Apple Account in iCloud on both. Step by step and troubleshooting: Coucou on iPhone.

My sessions don’t show up on the iPhone

Check that the Mac and the iPhone use the same Apple Account in iCloud and that Show my agent sessions on my iPhone is on in the Mac app, then pull down on the Agents tab to refresh. More in Coucou on iPhone.

macOS says it can’t verify the app

Coucou 0.1.1 and later are notarized by Apple: macOS only asks you to confirm the first launch. If you still have 0.1.0, open System Settings → Privacy & Security, scroll down and click Open Anyway, or update to the latest version.

After updating, macOS asks to let Coucou use my keys

That’s expected once after updating from 0.1.0, which was signed differently. Enter your Mac password and click Always Allow, once for each key you saved.

Where is the Windows download?

Here: Coucou-Windows.msi or Coucou-Windows-setup.exe, always the newest version (Windows 10/11). The installer isn’t code-signed yet, so SmartScreen may warn you: click More info → Run anyway. Microsoft Defender once flagged it by mistake; Microsoft reviewed it and removed the detection. If Defender still blocks it, update its definitions and try again.

Is there a Linux version?

Yes: an AppImage, a .deb and a .rpm for x86_64, in Coucou for Linux 0.5.0 (an Arch package can be built from the repository). The island sits on the top edge with compositors that support layer-shell (COSMIC, KDE Plasma, Hyprland, Sway…); on GNOME it sits at the top of the screen through XWayland. Please report anything odd in the issues.

Mochi doesn’t show my Claude Code sessions

Open Settings → Claude Code → Install hooks, review the changes, confirm, then start a new Claude Code session.

Can I use Coucou with Gemini CLI or Antigravity (agy)? (macOS)

Yes. Open Settings → Gemini CLI → Install hooks or Settings → Antigravity → Install hooks. The same backup-and-diff flow as Claude Code applies. Once installed, each gemini or agy session gets its own pill in the island.

The chat doesn’t answer

Add your API key in Settings: Settings → Anthropic API for Claude, or Settings → Chat — other providers (macOS) for Google AI (Gemini) or OpenAI. API usage is billed by the provider, separately from any subscription.

An integration pill stays grey

Check its key in Settings. Up to 4 pills can be active at once in addition to the main workspace tool — see Settings → Active pills.

What are Active pills? (macOS)

Active pills are the coding tools, agents and AI providers you declare in Settings → Active pills. The Main picker at the top lets you choose your primary workspace tool (VS Code, Cursor, Codex or Antigravity — GitHub build only). You can then add up to 4 more pills: Gemini CLI, Anthropic, Google AI, OpenAI and service integrations. An agent that sends coucou_agent in its hook payload still gets its own automatic pill regardless.

Can I use Coucou with Cursor? (macOS)

Yes. Install the Claude Code hooks (Settings → Claude Code → Install hooks). Claude Code started in Cursor's terminal then shows up on the Cursor pill, and its permission requests can be answered from the notch, like in VS Code. Cursor's own agent shows up too when Cursor loads Claude Code's hooks; its requests are still answered in Cursor. Pick Cursor as your Main tool if that's where you code.

Can I use Coucou with Codex? (macOS, GitHub build)

Yes. Open Settings → Codex Hooks → Install hooks. Coucou shows you the changes to ~/.codex/hooks.json before writing anything. Once installed, open Codex and run /hooks, or open Hooks in Codex's settings, to review and trust the hooks — Codex asks for this once. After that, your Codex sessions show up on the Codex pill, and permission requests show up with Allow and Deny in the notch.

Can I use Coucou with Apple Music? (macOS, GitHub build)

Yes. Open Settings → Active pills and toggle Apple Music on. The first time you use a playback control from the notch, macOS may ask you to allow Automation for Coucou — click OK. Once granted, the pill shows the current track and lets you play, pause and skip from the notch. Mochi dances while music plays.

Apple Music automation was denied

Open System Settings → Privacy & Security → Automation, find Coucou and enable the Music checkbox. You can also click Open Settings… in the Apple Music card in the notch, which takes you directly to that setting.

No sound

Check the speaker icon in the notch header and the volume in Settings.

Which model does the chat use?

On Mac, Claude Sonnet 4.6 by default (Anthropic). Switch provider and model by clicking the model name above the chat box. For Anthropic, the model can also be set in Settings → Anthropic API. Each model is billed at its own price by the provider.

Can I use Ollama or LM Studio instead of a cloud API?

Yes (macOS). Open Settings → Chat → Local models, type the server address (or leave blank for the default), and click Connect. Coucou checks that the server is reachable and lists available models. To stop using it, click Disconnect. No API key is needed; it is free: the model runs on your Mac.

Does it work without a notch?

Yes. On an iMac, a Mac mini, or a MacBook with its lid closed on an external display, Mochi sits in a small bar at the top of the main screen. With the lid open, it stays in the notch.

How do I uninstall?

Remove hooks first: Settings → Claude Code → Uninstall, and if you installed them, also Settings → Gemini CLI → Uninstall and Settings → Antigravity → Uninstall. If you installed the Plan usage status line (Settings → Agents → Plan usage), click Uninstall there first to restore your previous status line. Then quit the app and move it to the Trash. Optionally delete ~/Library/Application Support/NotchBuddy.

On Windows: same Uninstall button for the hooks, then Windows Settings → Apps → Coucou → Uninstall. Optionally delete %LOCALAPPDATA%\Coucou.

On Linux: same Uninstall button for the hooks, then sudo apt remove coucou or sudo dnf remove coucou, or delete the AppImage. Optionally delete ~/.config/coucou, ~/.local/share/coucou, ~/.local/share/fr.louisraille.coucou and ~/.cache/coucou.

Questions fréquentes

Comment avoir Coucou sur mon iPhone ?

Installe TestFlight depuis l’App Store, puis rejoins la bêta TestFlight. La bêta est gratuite ; Apple la limite à 10 000 testeurs. Ensuite, active Settings → General → iPhone dans l’app Mac (0.1.9 ou plus récent) et utilise le même compte Apple dans iCloud sur les deux. Étape par étape et dépannage : Coucou sur iPhone.

Mes sessions n’apparaissent pas sur l’iPhone

Vérifie que le Mac et l’iPhone utilisent le même compte Apple dans iCloud et que Show my agent sessions on my iPhone est activé dans l’app Mac, puis tire vers le bas sur l’onglet Agents pour actualiser. Plus de détails dans Coucou sur iPhone.

macOS dit qu’il ne peut pas vérifier l’app

Coucou 0.1.1 et les versions suivantes sont notarisées par Apple : macOS te demande seulement de confirmer le premier lancement. Si tu as encore la 0.1.0, ouvre Réglages Système → Confidentialité et sécurité, descends et clique sur Ouvrir quand même, ou installe la dernière version.

Après la mise à jour, macOS demande d’autoriser Coucou à utiliser mes clés

C’est normal une fois après la mise à jour depuis la 0.1.0, qui était signée autrement. Tape le mot de passe de ton Mac et clique sur Toujours autoriser, une fois par clé enregistrée.

Où est le téléchargement Windows ?

Ici : Coucou-Windows.msi ou Coucou-Windows-setup.exe, toujours la dernière version (Windows 10/11). L’installeur n’est pas encore signé, donc SmartScreen peut afficher un avertissement : clique sur Informations complémentaires → Exécuter quand même. Microsoft Defender l’avait détecté par erreur ; Microsoft l’a analysé et a retiré la détection. Si Defender le bloque encore, mets à jour ses définitions et réessaie.

Y a-t-il une version Linux ?

Oui : une AppImage, un .deb et un .rpm pour x86_64, dans Coucou for Linux 0.5.0 (un paquet Arch se construit depuis le dépôt). L’island se place sur le bord du haut avec les compositeurs qui gèrent layer-shell (COSMIC, KDE Plasma, Hyprland, Sway…) ; sous GNOME, elle se place en haut de l’écran via XWayland. Signale tout souci dans les issues.

Mochi n’affiche pas mes sessions Claude Code

Réglages → Claude Code → Install hooks, vérifie les changements, confirme, puis lance une nouvelle session Claude Code.

Puis-je utiliser Coucou avec Gemini CLI ou Antigravity (agy) ? (macOS)

Oui. Ouvre Réglages → Gemini CLI → Install hooks ou Réglages → Antigravity → Install hooks. Le même flux sauvegarde + diff qu’avec Claude Code s’applique. Une fois installé, chaque session gemini ou agy obtient sa propre pastille dans l’island.

Le chat ne répond pas

Ajoute ta clé d’API dans les Réglages : Réglages → Anthropic API pour Claude, ou Réglages → Chat — other providers (macOS) pour Google AI (Gemini) ou OpenAI. L’API est facturée par le fournisseur, à part de tout abonnement.

Une pastille reste grise

Vérifie sa clé dans les Réglages. Jusqu’à 4 pastilles peuvent être actives en même temps, en plus de l’outil de code principal — voir Réglages → Active pills.

Qu’est-ce que les Active pills ? (macOS)

Les Active pills sont les outils de code, agents et fournisseurs IA que tu déclares dans Réglages → Active pills. Le sélecteur Main en haut te permet de choisir ton outil principal (VS Code, Cursor, Codex ou Antigravity — version GitHub uniquement). Tu peux ensuite ajouter jusqu’à 4 pastilles supplémentaires : Gemini CLI, Anthropic, Google AI, OpenAI et des intégrations de services. Un agent qui envoie coucou_agent dans son payload obtient quand même sa pastille automatique.

Puis-je utiliser Coucou avec Cursor ? (macOS)

Oui. Installe les hooks Claude Code (Réglages → Claude Code → Install hooks). Claude Code lancé dans le terminal de Cursor apparaît alors sur la pastille Cursor, et tu peux répondre à ses demandes d’autorisation depuis le notch, comme dans VS Code. L’agent de Cursor apparaît aussi quand Cursor charge les hooks de Claude Code ; ses demandes se règlent encore dans Cursor. Choisis Cursor comme outil principal si c’est là que tu codes.

Puis-je utiliser Coucou avec Codex ? (macOS, version GitHub)

Oui. Ouvre Réglages → Codex Hooks → Install hooks. Coucou te montre les changements apportés à ~/.codex/hooks.json avant d’écrire quoi que ce soit. Une fois les hooks installés, ouvre Codex et tape /hooks, ou ouvre Hooks dans les réglages de l’app, pour les passer en revue et leur faire confiance — Codex ne te le demande qu’une fois. Ensuite, tes sessions Codex apparaissent sur la pastille Codex, et les demandes d’autorisation apparaissent avec Allow et Deny dans le notch.

Puis-je utiliser Coucou avec Apple Music ? (macOS, version GitHub)

Oui. Ouvre Réglages → Active pills et active Apple Music. La première fois que tu utilises un contrôle de lecture depuis le notch, macOS peut te demander d’autoriser l’Automatisation pour Coucou — clique sur OK. Une fois accordé, la pastille affiche le morceau en cours et te permet de lancer, mettre en pause et passer à la suite depuis le notch. Mochi danse pendant que la musique joue.

L’automatisation Apple Music a été refusée

Ouvre Réglages Système → Confidentialité et sécurité → Automatisation, trouve Coucou et coche la case Musique. Tu peux aussi cliquer sur Open Settings… dans la carte Apple Music du notch, qui t’y amène directement.

Pas de son

Vérifie l’icône haut-parleur dans l’en-tête du notch et le volume dans les Réglages.

Quel modèle utilise le chat ?

Sur Mac, Claude Sonnet 4.6 par défaut (Anthropic). Change de fournisseur et de modèle en cliquant sur le nom du modèle au-dessus du champ de chat. Pour Anthropic, le modèle peut aussi être défini dans Réglages → Anthropic API. Chaque modèle est facturé à son propre tarif par le fournisseur.

Puis-je utiliser Ollama ou LM Studio à la place d'une API cloud ?

Oui (macOS). Ouvre Réglages → Chat → Local models, entre l’adresse du serveur (ou laisse vide pour le défaut) et clique sur Connect. Coucou vérifie que le serveur est accessible et liste les modèles disponibles. Pour arrêter, clique sur Disconnect. Pas de clé d’API — c’est gratuit : le modèle tourne sur ton Mac.

Ça marche sans notch ?

Oui. Sur un iMac, un Mac mini ou un MacBook capot fermé branché à un écran externe, Mochi s’affiche dans une petite barre en haut de l’écran principal. Capot ouvert, il reste dans le notch.

Comment désinstaller ?

Retire d’abord les hooks : Réglages → Claude Code → Uninstall, et si tu les as installés, aussi Réglages → Gemini CLI → Uninstall et Réglages → Antigravity → Uninstall. Si tu as installé le relais Plan usage (Réglages → Agents → Plan usage), clique sur Uninstall d’abord pour retrouver ta status line d’avant. Puis quitte l’app et mets-la à la corbeille. Tu peux aussi supprimer ~/Library/Application Support/NotchBuddy.

Sous Windows : le même bouton Uninstall pour les hooks, puis Paramètres Windows → Applications → Coucou → Désinstaller. Tu peux aussi supprimer %LOCALAPPDATA%\Coucou.

Sous Linux : le même bouton Uninstall pour les hooks, puis sudo apt remove coucou ou sudo dnf remove coucou, ou supprime l’AppImage. Tu peux aussi supprimer ~/.config/coucou, ~/.local/share/coucou, ~/.local/share/fr.louisraille.coucou et ~/.cache/coucou.
