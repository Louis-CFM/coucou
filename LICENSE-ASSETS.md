# Name, character and artwork

The [MIT License](LICENSE) of this repository covers the **source code**. It was inherited from [Coucou](https://github.com/Louis-CFM/coucou) by Louis Raillé, whose brand and artwork (name, character, app icon, sounds and media) are reserved by their author and are **not** part of this fork.

This fork ships none of them:

- the mascot is a placeholder whale drawn in code (`NotchBuddy/Sources/NotchKit/Mascot.swift`);
- the app and menu bar icons are generated by `scripts/make-icons.swift`;
- the only sounds are macOS system sounds.

If you fork this project to ship your own app, give it your own name, icon, character and sounds.
