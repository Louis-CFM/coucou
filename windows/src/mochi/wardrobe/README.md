# Mochi's hats

One SVG per hat in `head/`. The file name is the id saved in settings,
`data-name` on the root is what the picker shows.

The art is generated by `scripts/wardrobe/` (Python, no dependencies): one
function per hat in `heads.py`, sharing the house material in `kit.py`. Edit
it, then run `python scripts/wardrobe/build.py`.

- Artboard `viewBox="0 0 200 200"` around the reference Mochi in
  `<g id="guide">` (ignored by the app): R = 50 at (100, 100), body 114 × 88.
- `data-seat="x y half"`: where the hat meets the head and the head's
  half-width there; `data-seat-yn`: how far down the head that is (-1 top).
  On other shapes the hat scales with the head's width at that height.
- `data-shadow="0"` for things too thin to shade the head (headbands).
- Groups with `data-swing="px py"` (a tassel) swing from that pivot.
- Keep everything below y = 14 so the small pill Mochis don't clip it.
- Allowed: `g`, `path`, `circle`, `ellipse`, `rect`, `defs`,
  `linearGradient`/`radialGradient` (userSpaceOnUse), `stop`, `clipPath`.
